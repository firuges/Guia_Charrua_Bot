💰 Sistema de Rewards

¿Qué es el Sistema de Rewards?

Sistema automático que entrega recompensas diarias y packs de bienvenida a los jugadores del servidor. Todo funciona de manera automática sin que tengas que hacer nada.

🎁 Tipos de Rewards

1. Daily Cash - Recompensa Diaria

¿Cómo funciona?
  • Se entrega automáticamente cada 24 horas cuando te conectas
  • Recibes dinero directamente en tu billetera
  • Cuantos más días consecutivos juegues, mayor es el bono
  • No necesitas hacer nada, se entrega automáticamente

⚠️ Importante: Si dejas de jugar por 1 día o más, tu racha se reinicia y vuelves a empezar desde el día 1.

2. Welcome Pack - Pack de Bienvenida

✅ Para nuevos jugadores:
  • Se entrega automáticamente la primera vez que te conectas
  • Incluye dinero inicial y items básicos de supervivencia
  • Solo lo recibes UNA VEZ (no se puede reclamar de nuevo)
  • Te ayuda a empezar tu aventura en el servidor
Ejemplo típico de Welcome Pack:

⏰ ¿Cuándo se entregan?

Las recompensas se entregan automáticamente cada 5 minutos mientras estás jugando. El sistema verifica:
  • Estás conectado al servidor
  • Ha pasado 24h desde tu última recompensa diaria
  • Nunca has recibido el welcome pack (solo para nuevos jugadores)

💬 Comandos del Sistema

⚠️ No hay comandos para jugadores
El sistema de rewards funciona completamente automático. No necesitas escribir ningún comando.

🎰 Sistema de Lotería

¿Qué es la Lotería?

Sistema de sorteos automáticos donde puedes ganar premios increíbles solo por estar jugando. El bot elige un ganador aleatorio cada cierto tiempo entre todos los jugadores conectados.

🎁 ¿Cómo Funciona?

Pasos del sorteo:
  1. Cada 30 minutos (configurable por el admin) se realiza un sorteo automático
  2. Todos los jugadores online participan automáticamente
  3. Se elige un ganador aleatorio
  4. El premio se selecciona usando sistema de weights (pesos)
  5. El premio se spawnea en la ubicación del ganador
  6. Si el premio tiene múltiples unidades (munición, flechas), se divide en stacks correctos
  7. Se anuncia al ganador en el chat del servidor

⚖️ Sistema de Pesos (Weights)

Cómo funcionan las probabilidades:

El sistema usa pesos enteros en lugar de porcentajes complicados. Cada premio tiene un "weight" (peso), y la probabilidad real se calcula dividiendo el peso del premio por la suma total de todos los pesos.

  • Total de weights: 1022 puntos distribuidos entre todos los premios
  • Ejemplo: Un premio con weight 5 tiene 5/1022 = 0.49% de probabilidad
  • Otro ejemplo: Un premio con weight 100 tiene 100/1022 = 9.78% de probabilidad

💡 Ventaja: Este sistema es más fácil de configurar y ajustar que los decimales tradicionales.

📦 Spawning de Premios con Múltiples Unidades

Sistema inteligente para munición y flechas:

Cuando ganas munición o flechas, el bot respeta los límites de stack del juego:

  • Munición 7.62x39mm: Max 30 por stack → 38 balas se spawnean como: 1 stack de 30 + 1 stack de 8
  • Calibre 9mm: Max 30 por stack → 40 balas = 1 stack de 30 + 1 stack de 10
  • Calibre 22: Max 20 por stack → 35 balas = 1 stack de 20 + 1 stack de 15
  • Flechas de Carbono: Max 12 por stack → 25 flechas = 2 stacks de 12 + 1 stack de 1

💡 Ventaja: Recibes stacks perfectamente divididos sin perder items por límites de stack.

Aumenta tus probabilidades comprando tickets:

Además de la ventaja VIP, puedes comprar tickets de lotería para incrementar aún más tus chances de ganar. Los tickets se suman con el multiplicador VIP para maximizar tu probabilidad.

  • 4 tiers disponibles (CONFIGURABLES!): Bronze ($500), Silver ($2,000), Gold ($5,000), Platinum ($15,000)
  • Boost acumulativo: Hasta +50% adicional de probabilidad

⏰ Cooldown de Ganadores (Configurable)

Sistema justo para todos:
Si ganas un sorteo, deberás esperar 3 sorteos (configurable) antes de poder ganar de nuevo. Esto asegura que todos los jugadores tengan oportunidad de ganar.
Ejemplo:
Si ganas a las 14:00, no podrás ganar de nuevo hasta después de los sorteos de 14:30, 15:00 y 15:30. Recién volverás a ser elegible en el sorteo de las 16:00.

  • on_win: Se resetean solo cuando ganas (los mantienes hasta ganar)

🚗 Sistema de Vehículos

Sistema Completo de Gestión de Vehículos

Protege tus vehículos con seguros, registra automáticamente la propiedad, controla robos y evita abusos de estacionamiento en zonas PVE.

🛡️ 1. Sistema de Seguros

¿Para qué sirve?
Si tu vehículo es destruido o robado, el seguro lo respawnea automáticamente después de un tiempo configurado (generalmente 24 horas).

Cómo comprar un seguro:

  1. Verifica el ID de tu vehículo (aparece en la pantalla cuando miras el vehículo)
  2. Escribe en el chat: !insurance_[ID] o !seguro_[ID]
  3. El bot verificará que el vehículo sea tuyo y que tengas dinero suficiente
  4. Se descontará el precio del seguro de tu balance
  5. Recibirás confirmación en el chat
Ejemplo:
!insurance_637683
Respuesta:
ElFiru, seguro comprado para tu BPC_Laika por $5000. El vehículo respawneará en 24 horas si es destruido.

📝 2. Registro Automático

Completamente automático:
Todos los vehículos se registran automáticamente con su dueño. No necesitas hacer nada.

¿Qué información se registra?

  • ID único del vehículo
  • Tipo de vehículo (auto, moto, avión, etc.)
  • Dueño actual (tu Steam ID y nombre)
  • Squad al que perteneces (si tienes uno)
  • Ubicación actual (coordenadas X, Y, Z)
  • Zona donde está estacionado (PVE o PVP)
  • Estado del seguro

⚔️ 4. Control Anti-PVP Abuse (Vehículos en PVE)

⚠️ Regla importante:
Si eres de un squad PVP o jugador PVP individual, NO puedes estacionar vehículos en zonas PVE cuando estás OFFLINE. Esto se considera abuse.

¿Cómo funciona el sistema?

  1. El bot detecta automáticamente si tienes banderas en zona PVP
  2. Si estacionas vehículos en zona PVE y estás OFFLINE, se considera violación
  3. Recibes 3 advertencias progresivas en Discord
  4. Si no corriges la violación, recibes multas automáticas
  5. Las multas se cobran cuando te conectas al servidor
✅ Parking permitido:
  • Si estás ONLINE, puedes estacionar donde quieras (para jugar)
  • Si eres de un squad PVE, puedes estacionar en PVE siempre
  • Si eres jugador PVP pero sin banderas en PVP, no hay restricción
❌ Parking NO permitido:
  • Squad PVP con vehículos en PVE mientras el dueño está OFFLINE
  • Jugador PVP individual con vehículos en PVE mientras está OFFLINE

🚖 Sistema de Taxi

¿Qué es el Sistema de Taxi?

Sistema de teletransporte rápido entre pads (zonas) del mapa. Paga una tarifa y viaja instantáneamente a tu destino sin necesidad de correr largas distancias.

🗺️ ¿Qué es un Pad?

Un pad es una zona específica del mapa identificada por una letra y un número:

Ejemplos de pads disponibles:
  • D4, D3, D2, D1, D0
  • C4, C3, C2, C1, C0
  • B4, B3, B2, B1, B0
  • A4, A3, A2, A1, A0
  • Z4, Z3, Z2, Z1, Z0

Cada pad representa un área grande del mapa. Puedes viajar a cualquier pad configurado.

💰 ¿Cuánto cuesta?

El costo varía según la distancia:
Cuanto más lejos viajes, más caro es el taxi. El precio se calcula automáticamente según tu ubicación actual y el destino.
Ejemplo:
Si estás en A0 y quieres ir a A1 (zona vecina) → $500
Si estás en A0 y quieres ir a D4 (cruzar todo el mapa) → $3,000

⏱️ Sistema de Cooldown Inteligente

✅ El sistema es justo y solo aplica cooldown cuando realmente usas el taxi

El cooldown del taxi se aplica de manera inteligente para no penalizarte por errores de validación que no son tu culpa:

🚫 NO se aplica cooldown cuando:

  • 🗺️ Estás en zona prohibida: Si intentas pedir taxi desde una zona prohibida, el sistema te rechazará pero NO te aplicará cooldown. Puedes reintentar inmediatamente después de salir de la zona
  • 📍 Ya estás en el destino: Si pides taxi al mismo pad donde ya estás, no tiene sentido aplicar cooldown
  • 🎯 Destino inválido: Si escribes mal el destino o pides un pad que no existe
  • 💰 Fondos insuficientes: Si no tienes suficiente dinero para pagar el taxi

💡 Ventaja: Esto significa que puedes intentar múltiples veces sin penalización si cometes errores o estás en una zona prohibida.

✅ SÍ se aplica cooldown cuando:

  • ✈️ Taxi completado exitosamente: Cuando el teleport se ejecuta correctamente (este es el comportamiento esperado)
  • ⏰ Intentas usar taxi en cooldown: Si ya tienes un cooldown activo y lo intentas de nuevo
  • 📝 Tienes solicitud pendiente: Si ya tienes un taxi en proceso y pides otro
Ejemplo práctico:

ANTES (Sistema antiguo):
1. Pides @taxi A4 desde Airfield Zone
2. Bot: "🚫 No puedes solicitar taxi desde esta zona: Airfield_Zone"
3. Bot: "El Firu, espera 159s antes de usar @taxi nuevamente" ❌ INJUSTO

AHORA (Sistema nuevo):
1. Pides @taxi A4 desde Airfield Zone
2. Bot: "🚫 No puedes solicitar taxi desde esta zona: Airfield_Zone"
3. Sales de la zona y pides @taxi A4 otra vez
4. Bot: "✅ Taxi procesado..." ✅ JUSTO (sin espera injusta)

🎯 Tipos de Taxi

Existen dos tipos de taxi:

Puedes activarlos en el config.yaml (taxi_OnGroundEnabled: false), al activar esta opcion se desactiva el Aereo

🚖 Taxi On Ground

Teleport directo al pad de destino

Este es el método estándar y más económico de viajar:

  • Funcionamiento: Te teletransporta directamente al nivel del suelo en el pad de destino
  • Zona de respawn: El Zones.yaml determina las zonas en las que puedes aparecer, el Respawn es aleatorio dentro de las zonas predefinidas
  • Llegada: Apareces de pie en el pad, listo para moverte
  • Costo: Precio base según distancia
  • Comando: @taxi [DESTINO] (por defecto usa este método)

✈️ Taxi con Redespliegue (Paracaidismo)

Teleport aéreo con paracaídas

Te teletransporta al aire sobre el destino y debes usar el paracaídas para aterrizar:

  • Paracaídas: El sistema te da un paracaídas automáticamente y te alerta de los segundos que tienes para ponertelo
  • Zona: La Zona de aparicion es aleatoria segun el Pad seleccionado.
  • Restricciones: Se pueden configurar Restricciones de zona de Respawn para que no te lance encima de POIS
  • Altura: Apareces a gran altura sobre el pad de destino
  • Aterrizaje: Tú controlas dónde aterrizar en el área del pad
  • Costo: Más caro que el taxi normal (recargo por el paracaídas)
  • Comando: @taxi [DESTINO] air o @taxi [DESTINO] parachute

Ventajas:

  • Mayor control del punto exacto de aterrizaje
  • Puedes ver el área desde arriba antes de aterrizar
  • Útil para reconocimiento táctico

⚠️ Importante: Asegúrate de abrir el paracaídas a tiempo para evitar morir por caída

📋 Cómo Usar el Taxi

Taxi Normal (On Ground)

Paso a paso:
  1. (Alert) Los comandos pueden usarse incluso dentro de squadron channel para evitar delatarte
  2. (Opcional) Consultar costo: Escribe @taxicosto D3
  3. Solicitar taxi: Escribe @taxi D3
  4. Confirmación: El bot verifica:
    • Tienes suficiente dinero
    • El pad de destino existe
    • Estás online
  5. Cobro: Se descuenta el dinero de tu balance
  6. Espera: El bot ejecuta el teleport (puede tardar 5-10 segundos)
  7. ¡Listo! Apareces en el pad de destino al nivel del suelo

Taxi con Paracaídas

Paso a paso:
  1. (Alert) Los comandos pueden usarse incluso dentro de squadron channel para evitar delatarte
  2. (Opcional) Consultar costo: Escribe @taxicosto D3 (el costo será mayor que el taxi normal)
  3. Solicitar taxi aéreo: Escribe @taxi D3 air o @taxi D3 parachute
  4. Confirmación y Cobro: El bot verifica y cobra el dinero (costo superior al taxi normal)
  5. Teleport: Apareces en el aire a gran altura sobre el pad de destino
  6. Paracaidismo:
    • El sistema te da un paracaídas automáticamente
    • Controlas tu caída y dirección de aterrizaje
    • ¡IMPORTANTE! Abre el paracaídas a tiempo para no morir
  7. ¡Listo! Aterrizas en el área del pad que elijas
⚠️ Importante:
  • El dinero se cobra ANTES del teleport
  • Si mueres durante el teleport, pierdes el dinero (no hay reembolsos)

  • No puedes cancelar una solicitud en progreso

🛡️ Sistema de Protección contra Abuso de Cancelaciones

Un sistema inteligente que detecta patrones de abuso (jugadores que cancelan frecuentemente después de recibir el paracaídas gratis) y aplica penalizaciones temporales justas.

🔍 Cómo Funciona:
  1. Tracking Automático: El sistema registra todas tus solicitudes, completados y cancelaciones de taxi
  2. Protección para Nuevos: Los jugadores con menos de 10 taxis NO reciben penalizaciones (período de aprendizaje)
  3. Análisis de Patrones: Se calcula un "abuse score" basado en tu comportamiento:
    • 50% peso: Cancelaciones DESPUÉS de recibir paracaídas
    • 30% peso: Cancelaciones totales
    • 20% peso: Frecuencia reciente (últimas 24h)
  4. Estados Progresivos:
    • Normal (0-29% abuse): Sin penalizaciones
    • ⚠️ SOSPECHOSO (30-49% abuse): Cooldown x1.5 (ej: 60min → 90min)
    • 🚨 SANCIONADO (50%+ abuse): Cooldown x2.5 (ej: 60min → 150min)

  • Tu estado actual
  • Cuánto tiempo de cooldown adicional tienes
  • Cómo rehabilitarte (completar 5 taxis exitosos)
✅ Sistema de Rehabilitación:
  • Decaimiento de Score: Cada taxi completado exitosamente reduce tu abuse score en 5%
  • Limpieza de Sanciones: Completa 5 taxis exitosos y tu estado SANCIONADO desaparece
  • Segunda Oportunidad: El sistema premia el buen comportamiento

📦 Protección Anti-Abuse de Cofres en PVE

¿Qué es este sistema?

Sistema que detecta y penaliza a squads/jugadores PVP que guardan cofres en zonas PVE, obteniendo almacenamiento seguro mientras juegan PVP. Similar al sistema de vehículos.

⚔️ ¿Por qué existe este sistema?

El problema que resuelve:
Algunos jugadores PVP colocan cofres en zonas PVE para tener almacenamiento 100% seguro (nadie puede atacarlos en PVE), mientras ellos juegan PVP y atacan a otros. Esto es considerado "abuse" o trampa.
✅ Regla simple:
Si eres de un squad PVP (tienes banderas en zona PVP), NO puedes tener cofres en zonas PVE. Debes guardar tus cosas en zonas PVP como todos los jugadores PVP.

🔍 ¿Cómo funciona la detección?

El sistema detecta automáticamente:
  1. Tu squad tiene banderas en zona PVP → Eres squad PVP
  2. Tienes cofres (de cualquier tipo) en zonas PVE
  3. Se marca como violación

Tipos de cofres detectados:

  • 📦 Cofres de base (construidos)
  • 🎒 Cofres virtualizados (dejados en el suelo)
  • 📦 Contenedores de cualquier tipo

⚠️ Sistema de Advertencias

No se multa inmediatamente. Recibes advertencias primero:
  1. 1° Advertencia: Notificación en Discord - "Tienes X cofres en PVE, muévelos a PVP"
  2. 2° Advertencia: Notificación en Discord - "Segunda advertencia. En la próxima multa se expondrán las coordenadas de tus cofres"
  3. 3° Advertencia: Notificación en Discord - "Última advertencia antes de multa"
  4. Multa: Se aplica multa económica + se exponen públicamente las coordenadas de todos tus cofres en PVE
🗺️ Exposición de coordenadas:
Cuando recibes la multa, el bot publica en Discord las coordenadas exactas (X, Y, Z) de TODOS tus cofres en PVE. Esto permite que otros jugadores encuentren y raideen tus cofres.

💰 Multas

✅ Cómo evitar multas

Opciones para evitar violaciones:

  2. Opción 2: Remueve tus banderas PVP (cambiate a squad PVE)
  3. Opción 3: Elimina los cofres que están en PVE
✅ Squads permitidos tener cofres en PVE:
  • Squads PVE (sin banderas en PVP)

🔄 Protección Anti-Lock en Respawns

¿Qué es el Sistema Anti-Lock?

Sistema que detecta y penaliza el abuse de lockear vehículos en zonas de respawn, impidiendo que otros jugadores usen los vehículos de spawn.

⚔️ ¿Qué problema resuelve?

El abuse detectado:
Algunos jugadores van a las zonas de respawn de vehículos y lockean todos los vehículos que aparecen, impidiendo que otros jugadores puedan usarlos. Esto se considera "griefing" o abuse.
Ejemplo de abuse:
Un jugador va al respawn de autos en el pad C3. Cada vez que aparece un auto nuevo, lo lockea inmediatamente. Ahora nadie más puede usar esos autos, pero él tampoco los está usando. Solo está bloqueando el acceso.

🔍 ¿Cómo funciona la detección?

El sistema detecta automáticamente:
  1. Vehículos spawneados en zonas de respawn conocidas
  2. Vehículos que son lockeados inmediatamente después del spawn
  3. Vehículos lockeados que permanecen en la zona de respawn (no están siendo usados)
  4. Jugador que lockea múltiples vehículos en la misma zona

¿Qué NO es abuse?

✅ Uso legítimo:
  • Lockear un vehículo y USARLO (alejarte de la zona de respawn)
  • Lockear tu vehículo personal que NO está en zona de respawn
  • Lockear un vehículo que trajiste de otro lugar
❌ Abuse detectado:
  • Lockear múltiples vehículos en zona de respawn sin usarlos
  • Lockear vehículos de respawn y dejarlos ahí bloqueados
  • Volver repetidamente a lockear vehículos de respawn

📖 Sistema de Límites de Vehículos

¿Qué es este sistema?

El Sistema de Límites de Vehículos controla la cantidad máxima de vehículos que pueden tener los Squads, miembros de squad y jugadores individuales. Incluye un sistema progresivo de advertencias, multas económicas y destrucción automática para prevenir el acaparamiento de vehículos.

🎯 ¿Cómo funciona?

1️⃣ Niveles de Control

🏛️ Límites por Squad

Control del total de vehículos que puede tener un squad completo:

  • Total máximo: 50 vehículos por squad
  • Por tipo:
    • Motos: 20 máximo
    • Autos: 15 máximo
    • Camiones: 5 máximo
    • Aviones: 3 máximo
    • Botes: 3 máximo

👤 Límites por Miembro de Squad

Control individual para cada miembro dentro de un squad:

  • Total máximo: 3 vehículos por miembro
  • Por tipo: 1-2 vehículos dependiendo del tipo

🚶 Límites por Jugador Individual

Control para jugadores sin squad:

  • Total máximo: 3 vehículos
  • Por tipo: 1 vehículo de cada tipo

⭐ Conceptos Clave del Sistema (IMPORTANTE - Leer Primero)

🛡️ Protección para Jugadores Offline ("Modo Skip")

El sistema está configurado en modo skip para protegerte cuando estás offline:

  • ¿Qué significa "skip"? Si estás OFFLINE cuando el sistema intenta enviarte una warning o multa, la acción se "salta" (skip) - NO se envía y NO se cuenta
  • ¿Evito multas desconectándome? ❌ NO - Solo las RETRASA. Cuando vuelvas online, el sistema continúa donde quedó
  • Ejemplo práctico: Si debes recibir Warning #2 pero estás offline → El sistema la "skipea" → Cuando vuelvas online la envía inmediatamente
  • 💡 Beneficio: NUNCA recibirás multas sin haber recibido las 3 warnings, sin importar cuánto tiempo estés offline
⏰ Grace Period (24 Horas CORRIDAS) vs Warnings

Entender la diferencia es crucial:

  • Grace Period: Timestamp ABSOLUTO de 24h desde la detección (cuenta siempre, online o offline)
  • Warnings: Solo se envían y cuentan cuando estás ONLINE (modo skip)
  • Ejemplo: Grace period expira en DÍA 2, pero si solo enviaste 1 warning porque estuviste offline → NO puede multar hasta enviar las 3 warnings
  • 📊 Doble Protección:
    • ✅ Grace period debe haber expirado (24h corridas)
    • ✅ Deben haberse enviado mínimo 3 warnings
🔄 Sistema de Auto-Restart (Enforcement Continuo)

Si alcanzas el máximo de multas (3) pero NO corriges el exceso:

  • ¿Qué pasa? El sistema auto-resuelve la violación y crea una NUEVA automáticamente
  • Nuevo ciclo: Grace period 24h + 3 warnings + 3 nuevas multas ($47,500 adicionales)
  • ¿Cuántas veces? Indefinidamente hasta que corrijas el exceso
  • Costo acumulado: Semana 1: $47,500 | Semana 2: $95,000 | Mes 1: $190,000+
  • 💡 Recomendación: Te sale más barato destruir/regalar los vehículos excedentes
⚠️ ADVERTENCIAS IMPORTANTES
  • ❌ Desconectarse NO evita las multas - Solo las retrasa hasta que vuelvas
  • ❌ Las multas NO se acumulan - Si estás offline 1 mes después de Multa #2, cuando vuelvas recibes SOLO Multa #3 (no 30 multas acumuladas)
  • ✅ El sistema es JUSTO - Siempre recibirás 3 warnings antes de cualquier multa, sin importar cuánto tiempo estés offline
  • ✅ Intervalos permisivos - Warnings: 8h | Multas: 12h desde la última ENVIADA/APLICADA (no se apilan)
  • 🔄 El ciclo continúa - Si no corriges, el sistema reinicia automáticamente (nueva violación, nuevas warnings, nuevas multas)

2️⃣ Sistema Progresivo de Acciones

Fase 1: Período de Gracia (24 horas CORRIDAS)

Cuando excedes los límites, entras en un período de gracia donde recibes advertencias:

  • 3 advertencias obligatorias: El sistema REQUIERE enviar 3 warnings antes de poder multar
  • Intervalo entre warnings: 8 horas desde el último warning ENVIADO
  • Grace period: 24 horas CORRIDAS desde la detección (timestamp absoluto)
  • Protección offline: Si estás offline, las warnings NO se envían ni cuentan (modo skip)
  • Al reconectar: Recibes las warnings pendientes inmediatamente (si ya pasó el cooldown)
  • Recibes notificación in-game si estás conectado
  • Se envían webhooks a Discord

⚠️ Importante: Ambas condiciones deben cumplirse para que se apliquen multas:

  • ✅ Grace period de 24h debe haber expirado
  • ✅ Deben haberse enviado mínimo 3 warnings
Fase 2: Multas Progresivas

Si no reduces tus vehículos después de las advertencias:

  • Multa 1: $10,000 (monto base)
  • Multa 2: $15,000 (1.5x)
  • Multa 3: $22,500 (2.25x)
  • Total multas: $47,500 si no corriges

Intervalos permisivos:

  • 12 horas desde la última multa APLICADA
  • Si estás offline, la multa NO se aplica (modo skip)
  • Al reconectar: Se aplica UNA multa (la que corresponde), no se acumulan
  • El dinero se descuenta automáticamente de tu balance
Fase 3A: Destrucción Automática (Si está habilitada)

Después de 3 multas sin cumplir, los vehículos excedentes se destruyen automáticamente:

  • Se destruyen los vehículos más antiguos primero
  • Recibes notificación de cuáles fueron destruidos
  • No hay forma de recuperarlos
Fase 3B: Reinicio Automático de Ciclo (Si destrucción está deshabilitada) 🔄

Si la destrucción está deshabilitada, el sistema REINICIA el ciclo de enforcement:

  • Al alcanzar 3 multas: Recibes aviso en el webhook de Multa #3
  • Auto-resolución: La violación actual se cierra automáticamente
  • Nueva violación: Si sigues en exceso, se crea automáticamente en el próximo check (30 min)
  • Nuevo ciclo completo: Grace period 24h → 3 warnings → 3 multas ($47,500 adicionales)
  • Continúa indefinidamente: Hasta que corrijas el exceso de vehículos

💰 Costo acumulativo si no corriges:

  • Semana 1: $47,500
  • Semana 2: $95,000
  • Semana 3: $142,500
  • Mes 1: $190,000+

💡 Conclusión: Te conviene más destruir/regalar los vehículos excedentes que pagar multas indefinidamente.

3️⃣ Detección de Vehículos Sin Candado en Banderas (Anti-Exploit)

🔓 Sistema de 2 Pasos - Advertencia + Destrucción

El sistema detecta TODOS los vehículos sin candado (unlocked/sin owner) dentro de las zonas de bandera de squad:

  • Detección 100%: NO requiere que el squad esté en límite - detecta cualquier vehículo sin candado en tu bandera
  • Paso 1 - Primera Detección: Advertencia in-game + Discord embed naranja
  • Período de Gracia: 30 minutos para colocar candados (configurable)
  • Paso 2 - Segunda Detección: Si no se corrigió después del grace period → Destrucción automática
  • Felicitación: Si corriges a tiempo (colocas candados), recibes mensaje de felicitación
  • Calcula automáticamente áreas de banderas (radio configurable)

❓ Preguntas Frecuentes (FAQ)

Q: ¿Puedo evitar las multas desconectándome del servidor?

R: ❌ NO. Desconectarse solo RETRASA las multas, no las evita. El sistema usa "modo skip" - cuando estás offline, las warnings y multas se ponen en pausa. Cuando vuelvas online, el sistema continúa exactamente donde quedó. Ejemplo: Si te desconectas después de Warning #1 y vuelves 1 semana después, recibirás Warning #2 inmediatamente (el cooldown de 8h expiró hace días).

Q: Si estoy offline 1 mes, ¿me cobran 60 multas acumuladas?

R: ❌ NO. Las multas NO se acumulan. El sistema solo cobra la multa que CORRESPONDE según tu contador. Ejemplo: Si te desconectas después de Multa #2 y vuelves 1 mes después, solo recibirás Multa #3 ($22,500), no 30 multas de $22,500. El sistema respeta intervalos de 12h entre multas.

Q: ¿Qué pasa si el grace period expira pero estuve offline y solo recibí 1 warning?

R: ✅ El sistema tiene DOBLE PROTECCIÓN. Aunque el grace period expire (timestamp de 24h), el sistema NO puede multar hasta que se envíen MÍNIMO 3 warnings. Esto te protege si estuviste offline durante el grace period. Cuando vuelvas online, recibirás las warnings pendientes ANTES de cualquier multa.

Q: ¿Cómo funciona el "auto-restart" del sistema?

R: Cuando alcanzas el máximo de multas (3 = $47,500 total) pero NO corriges el exceso de vehículos, el sistema automáticamente:

  • 1️⃣ Te envía un aviso en el webhook de Multa #3: "Máximo de multas alcanzado - El proceso se reiniciará"
  • 2️⃣ Auto-resuelve la violación actual (la cierra)
  • 3️⃣ En el próximo check (30 min), si SIGUES en exceso, crea una NUEVA violación con contadores en 0
  • 4️⃣ Comienza un NUEVO ciclo completo: Grace 24h → 3 warnings → 3 multas → $47,500 adicionales
  • 5️⃣ Este ciclo se repite INDEFINIDAMENTE hasta que corrijas
Costo total si no corriges: Semana 1: $47,500 | Semana 2: $95,000 | Mes 1: $190,000+

Q: ¿Por qué el grace period es de "24 horas CORRIDAS"?

R: El grace period es un timestamp ABSOLUTO desde el momento de detección. Cuenta siempre (online o offline). Ejemplo: Detección DÍA 1 10:00 → Grace expira DÍA 2 10:00 (exactamente 24h después). Esto evita que jugadores abusen desconectándose indefinidamente. PERO el sistema TAMBIÉN requiere mínimo 3 warnings enviados, así que estás protegido si estuviste offline.

Q: ¿Los intervalos de warnings y multas se acumulan si estoy offline?

R: ❌ NO. Los intervalos cuentan desde la última warning/multa ENVIADA/APLICADA (no desde intentos fallidos). Ejemplo: Warning #1 enviada DÍA 1 10:00 → Te desconectas 1 semana → Vuelves DÍA 8 → Warning #2 se envía INMEDIATAMENTE (el cooldown de 8h expiró hace 6 días).

Q: ¿Cuál es la mejor estrategia si recibo warnings?

R: ✅ CORRIGE INMEDIATAMENTE. Las opciones:

  • Opción 1: Destruir vehículos excedentes (#DestroyVehicle)
  • Opción 2: Quitar candado y regalarlos a otros jugadores (#Unlock)
  • Opción 3: Mover vehículos fuera de la bandera (si es violación de squad)
Si corriges durante el grace period (24h), la violación se auto-resuelve y NO pagas multas. Una vez que corrijas, recibirás un webhook de confirmación: "✅ Infracción de Límites Resuelta".

Q: ¿Puedo consultar mi estado actual de violación?

R: Los admins pueden revisar el archivo data/vehicle_limits/violations.json que contiene:

  • warnings_sent: Cuántas warnings has recibido
  • fines_applied: Cuántas multas has pagado
  • total_fines_amount: Total pagado en multas
  • grace_period_ends: Cuándo expira tu grace period
  • status: GRACE_PERIOD o ACTIVE
Todos los cambios también se envían a Discord vía webhooks.

📖 Sistema de Alertas de Robo de Vehículos

¿Qué es este sistema?

El Sistema de Alertas de Robo detecta cuando un vehículo cambia de propietario y envía alertas in-game y por Discord. Puede configurarse para alertar solo a jugadores VIP o a todos los jugadores.

🎯 ¿Cómo funciona?

1️⃣ Detección de Cambios de Propietario

🔍 ¿Qué detecta?

El sistema monitorea continuamente los vehículos y detecta cuando:

  • Cambio de propietario: El vehículo ahora pertenece a otra persona
  • Cambio de squad: El vehículo cambió de un squad a otro
  • Vehículo robado mientras offline: El cambio ocurrió cuando el dueño no estaba conectado
  • Robo confirmado: El cambio persiste por más de 24 horas (robo permanente)

2️⃣ Tipos de Cambios

🚨 Cambio Externo (Robo Real)

Cuando un vehículo cambia a un squad diferente o a un jugador sin squad:

  • Se envía alerta inmediata
  • Indica robo probable
  • Mensaje: "⚠️ ALERTA: PlayerX perdió su Auto ID#12345 - Nuevo owner: LadronY"
ℹ️ Cambio Intra-Squad

Cuando un vehículo cambia entre miembros del mismo squad:

  • Normalmente desactivado (transferencia legítima)
  • Puede activarse si quieres monitorear transferencias internas
  • Mensaje: "ℹ️ Auto ID#12345 transferido de PlayerX a PlayerY (mismo squad)"

3️⃣ Modo VIP-Only

👑 Alertas Solo para VIPs (Recomendado)

Configuración más común para servidores:

  • Solo jugadores VIP reciben alertas cuando les roban
  • Reduce spam de notificaciones
  • Premia la membresía VIP con seguridad extra

Ejemplo:
- Si le roban vehículo a VIP → SE ENVÍA ALERTA ✅
- Si le roban vehículo a no-VIP → NO se envía alerta ❌

🌐 Modo Alertas para Todos

Puede configurarse para enviar alertas a cualquier jugador:

  • Todos reciben alertas de robo
  • Mayor cantidad de notificaciones
  • Útil en servidores pequeños

4️⃣ Vehículos de Alto Valor

🔥 Prioridad Especial

Algunos vehículos reciben alertas prioritarias:

  • SUVs Blindados
  • Hummers
  • Autos de Policía
  • Helicópteros (si existen)

Estas alertas se envían siempre, independientemente del modo VIP.

5️⃣ Detección de Robo Offline

🚨 Robo Mientras Desconectado

El sistema detecta robos que ocurren cuando el dueño no está conectado:

  • Rastrea el estado online/offline de los jugadores
  • Identifica robos aprovechando ausencia
  • Mensaje especial: "🚨 ROBO MIENTRAS OFFLINE: PlayerX perdió su vehículo mientras estaba desconectado"

6️⃣ Confirmación de Robo Permanente

🔒 Robo Confirmado (24 horas)

Si un cambio persiste por 24 horas:

  • Se considera robo permanente
  • Se envía alerta de confirmación
  • Mensaje: "🔒 ROBO CONFIRMADO: Auto ID#12345 robado permanentemente de PlayerX por LadronY"

📊 Ejemplo de Flujo

Caso: VIP le roban un auto

T=0: Sistema detecta cambio de propietario
T=0: Verifica: ¿Es VIP el dueño anterior? → Sí
T=0: ¿Es cambio externo (diferente squad)? → Sí
T=0: ALERTA ENVIADA: "⚠️ ALERTA: VIP_Player perdió su Auto ID#12345"
T=24h: Cambio persiste → "🔒 ROBO CONFIRMADO: Auto robado permanentemente"

❌ Problemas Comunes

1. No recibí alerta cuando me robaron

Posibles causas:
  • No eres VIP: Si el modo VIP-only está activado, solo VIPs reciben alertas
  • Cambio intra-squad: Si fue transferencia dentro del mismo squad, puede estar desactivado
  • No estabas conectado: Las alertas in-game solo se envían si estás online
  • Webhook deshabilitado: Las alertas por Discord pueden estar apagadas
✅ Cómo verificar:
Revisa ownership_changes.json para ver si hay registro del cambio. Si existe, el sistema lo detectó pero no envió alerta por la configuración.

2. Recibo demasiadas alertas

Esto puede ocurrir si:
  • Las alertas intra-squad están habilitadas (transferencias internas)
  • Modo "alert_for_all" está activo (alertas para todos)
  • Hay muchos robos legítimos en el servidor
✅ Solución:
Contacta al admin para ajustar los filtros de alertas. Recomendado: VIP-only mode + solo cambios externos.

3. El cambio fue legítimo pero recibí alerta de "robo"

Transferencias legítimas que activan alertas:
  • Vendiste o regalaste el vehículo a alguien de otro squad
  • Saliste del squad y el vehículo quedó con otro miembro
  • Hubo un cambio de líder de squad
✅ Solución:
El sistema detecta cambios de propietario, no puede distinguir entre robo y transferencia voluntaria. Esto es normal y esperado.

4. No apareció alerta de "robo confirmado" después de 24h

La alerta de robo permanente se envía solo si:
  • El vehículo todavía existe después de 24h
  • El propietario no cambió nuevamente
  • El vehículo no fue destruido
✅ Cómo verificar:
En ownership_changes.json busca el campo "permanent": true después de 24h. Si no está, es porque el vehículo ya no existe o cambió de dueño nuevamente.

5. Soy VIP pero no recibo alertas

Verifica en la configuración:
  • Confirma que tu Steam ID está en la lista de VIPs
  • Verifica que vip_only.enabled = true
  • Verifica que alerts.enabled = true
✅ Cómo verificar:
Contacta al admin y proporciona tu Steam ID. Ellos pueden verificar en el config si estás en la lista VIP correctamente.

6. ¿Dónde veo el historial de todos los robos?

Archivo de historial:
data/vehicles/ownership_history/ownership_changes.json

Este archivo contiene todos los cambios de propietario detectados, incluyendo:

  • Fecha y hora del cambio
  • Propietario anterior y nuevo
  • Squad anterior y nuevo
  • Si el dueño anterior estaba online
  • Si es cambio permanente (24h+)

📖 Sistema VIP

¿Qué es el Sistema VIP?
El Sistema VIP es una configuración centralizada que otorga beneficios especiales a jugadores premium en múltiples features del bot. Una vez que eres agregado como VIP, automáticamente recibes ventajas en todos los sistemas compatibles.

🎯 ¿Cómo funciona?

🔑 Lista Centralizada de VIPs

El administrador mantiene una lista única de Steam IDs VIP en la configuración del bot. Esta lista se usa automáticamente en todos los sistemas que soportan VIP.

Importante: No necesitas registrarte en cada sistema. Una vez agregado como VIP, todos tus beneficios se activan automáticamente.

👑 Beneficios VIP por Sistema

1️⃣ Sistema de Lotería

Ventaja: Mayor probabilidad de ganar
  • Multiplicador: 1.5x (50% más chances)
  • Ejemplo: Si un jugador normal tiene 10% de probabilidad, un VIP tiene 15%
  • Se aplica automáticamente en cada sorteo
  • Visible en logs del sistema

2️⃣ Sistema de Límites de Vehículos

Ventajas: Período de gracia extendido y multas reducidas
  • Período de gracia: 48 horas (normal: 24h)
  • Multas: 50% de descuento
    • Multa 1: $5,000 (normal: $10,000)
    • Multa 2: $7,500 (normal: $15,000)
    • Multa 3: $11,250 (normal: $22,500)
    • Total VIP: $23,750 (normal: $47,500)
  • Límites: Los mismos (juego justo)

3️⃣ Sistema de Alertas de Robo

Ventaja: Alertas prioritarias de robo
  • Recibes alertas inmediatas cuando te roban un vehículo
  • Alertas in-game si estás conectado
  • Webhooks a Discord
  • Seguimiento de robos offline
  • Confirmación de robo permanente (24h)

4️⃣ Sistema de Seguros de Vehículos

Ventaja: Descuentos y beneficios especiales
  • Descuentos en primas de seguros (si configurado)
  • Mayor cobertura o mejores términos
  • Prioridad en procesamiento de claims

5️⃣ Comandos de Chat

Ventaja: Acceso a comandos especiales
  • Cooldowns reducidos en comandos
  • Acceso a comandos VIP-only (si existen)
  • Prioridad en procesamiento de comandos

⚙️ Sistema de Administradores Silenciosos

🎭 Silent Admins

Los administradores pueden configurar un nombre ficticio que aparecerá en el chat en lugar de su nombre real:

  • Propósito: Permite a admins probar el bot sin revelar su identidad
  • Funcionamiento: Los comandos y recompensas van al personaje real, pero el chat muestra el nombre ficticio
  • Ejemplo: Admin "El_Firu" configurado como "Goku" → Chat muestra "Goku ganó la lotería" pero el premio va a "El_Firu"
  • Transparencia: No afecta el gameplay, solo oculta la identidad en mensajes públicos

❌ Problemas Comunes

1. No recibo beneficios VIP

Causas posibles:
  • Tu Steam ID no está en la lista VIP
  • Tu Steam ID está mal escrito
  • El sistema VIP está deshabilitado (enabled: false)
  • El bot no recargó la configuración después de agregarte
✅ Solución:
  1. Contacta al admin y proporciona tu Steam ID correcto
  2. Verifica que usas el formato correcto: "76561198059658346"
  3. Pide al admin que ejecute @reload_config
  4. Espera 1 minuto y prueba nuevamente

2. Recibí beneficio VIP en un sistema pero no en otro

Cada sistema puede tener su propia configuración VIP:
  • Lotería: Sección lottery.vip.multiplier
  • Alertas Robo: Sección vehicle_ownership.alerts.vip_only.enabled
  • Límites Vehículos: Detecta automáticamente desde vip_system
✅ Solución:
Si un sistema no reconoce tu VIP, el admin debe verificar que ese sistema específico tenga habilitado el soporte VIP en su configuración.

3. Mi Steam ID es correcto pero no funciona

Formato de Steam ID:
  • Correcto: "76561198059658346" (con comillas)
  • Incorrecto: 76561198059658346 (sin comillas)
  • Incorrecto: "STEAM_0:1:123456" (formato antiguo)
  • Incorrecto: "[U:1:123456]" (formato Steam3)
✅ Cómo obtener tu Steam ID correcto:
  1. Ve a steamid.io
  2. Ingresa tu perfil de Steam
  3. Copia el steamID64 (número largo de 17 dígitos)
  4. Proporciona ese número al admin

4. Era VIP pero dejé de serlo

Posibles razones:
  • El admin removió tu Steam ID de la lista
  • Tu membresía VIP expiró (si es temporal)
  • Hubo un error al actualizar la configuración
  • El sistema VIP fue deshabilitado globalmente
✅ Solución:
Contacta al administrador para verificar tu estado VIP y renovar si es necesario.

📡 Sistema de Webhooks

¿Qué son los Webhooks?

Los webhooks son notificaciones automáticas que el bot envía a Discord cuando ocurren eventos importantes en el servidor. Son embeds (mensajes enriquecidos) que muestran información detallada con formato profesional.

🎯 ¿Para Qué Sirven?

Monitoreo en Tiempo Real:
  • Estado del servidor: Jugadores online, features activas, estado del bot
  • Leaderboards automáticos: Rankings actualizados cada hora
  • Violaciones y multas: Notificaciones de infracciones de límites
  • Bunkers activos: Estado actual de bunkers en el mapa
  • Alertas de robo: Notificaciones cuando roban vehículos
  • Violaciones PVE: Alertas de cofres/vehículos en zonas prohibidas

⚙️ Características Principales

🔄 Actualización Automática

Los webhooks pueden configurarse para actualizar mensajes existentes en lugar de crear nuevos:

  • Método "update": Edita el mismo mensaje (ideal para stats)
  • Método "create": Crea mensaje nuevo cada vez (ideal para alertas)
  • Intervalos configurables: Desde 1 minuto hasta 7 días

📌 Múltiples Endpoints

Puedes configurar diferentes canales de Discord para diferentes tipos de notificaciones:

  • Canal de stats del servidor
  • Canal de leaderboards
  • Canal de alertas/warnings
  • Canal de multas/fines
  • Canal de admin/logs

🎨 Embeds Personalizables

Los webhooks usan embeds de Discord con colores, iconos y campos personalizados:

  • Colores: Cada evento tiene su color distintivo
  • Iconos: Avatar y thumbnail personalizables
  • Campos: Información organizada en secciones
  • Timestamps: Fecha y hora de última actualización

🛠️ ¿Cómo Funciona?

Flujo de Webhooks:
  1. Evento ocurre: Algo sucede en el servidor (sorteo de lotería, jugador excede límite, etc.)
  2. Bot procesa: El bot recopila la información relevante
  3. Webhook se envía: Se crea/actualiza un embed en Discord
  4. Notificación visual: Los admins/jugadores ven la información en tiempo real

📋 Configuración Básica

📁 Archivo de configuración:

config/config.yaml

La sección webhooks contiene toda la configuración del sistema.

Estructura básica: 
webhooks:
  enabled: true  # Master switch

  global:
    retry_count: 3
    timeout_seconds: 10
    max_concurrent_webhooks: 5

  endpoints:
    - id: "server_status"
      webhook_url: "https://discord.com/api/webhooks/..."
      event_types:
        - "server_status"
        - "bunkers_active"

  events:
    server_status:
      enabled: true
      method: "update"
      update_interval_minutes: 10

🔑 Elementos Clave

Master Switch:
webhooks.enabled: true - Si está en false, NINGÚN webhook funciona.
Endpoints:
Son las URLs de Discord donde se envían los mensajes. Cada endpoint puede suscribirse a múltiples eventos.
Events:
Configuración individual de cada tipo de evento (intervalo, método, formato del embed).

⚙️ Configuración de Webhooks

📁 Ubicación:

config/config.yaml

Sección: webhooks

🔑 Configuración Global

Global Settings: 
webhooks:
  enabled: true  # Master switch - deshabilita TODO el sistema si es false

  global:
    retry_count: 3                  # Reintentos en caso de fallo
    timeout_seconds: 10             # Timeout de petición HTTP
    retry_delay_seconds: 2          # Delay entre reintentos
    max_concurrent_webhooks: 5      # Webhooks simultáneos máximos
    use_custom_templates: true      # Usar templates personalizados

📍 Configurar un Endpoint

Endpoint Example: 
endpoints:
  - id: "server_status"                    # ID único del endpoint
    enabled: true                          # Habilitar/deshabilitar
    webhook_url: "https://discord.com/api/webhooks/..." # URL de Discord
    webhook_name: "SCUM Server Status"     # Nombre del webhook
    webhook_icon_url: "https://..."        # Icono del avatar
    event_types:                           # Eventos suscritos
      - "server_status"
      - "bunkers_active"
Cómo obtener una Webhook URL de Discord:
  1. Ve al canal de Discord donde quieres recibir notificaciones
  2. Click derecho en el canal → Editar canal
  3. Ve a la sección Integraciones
  4. Click en Crear Webhook
  5. Dale un nombre y avatar (opcional)
  6. Click en Copiar URL del Webhook
  7. Pega esa URL en webhook_url

⚙️ Configurar un Evento

Event Example - Server Status: 
events:
  server_status:
    enabled: true                       # Habilitar evento
    method: "update"                    # "update" o "create"
    update_interval_minutes: 10         # Frecuencia de actualización
    update_on_startup: true             # Actualizar al iniciar bot

    # Configuración específica
    include_features: true              # Mostrar features activas
    include_players_online: true        # Mostrar jugadores online
    show_player_names: true             # Mostrar nombres individuales

    # Personalización del embed
    embed:
      title: "📊 Estado del Servidor SCUM"
      color: 0x0080FF                   # Azul (hex color)
      description: "Información general del servidor"
      thumbnail_url: "https://..."
      show_thumbnail: true
      footer_text: "Última actualización"
      include_timestamp: true

      # Campos personalizados
      fields:
        - name: "🤖 Estado del Bot"
          value: "{bot_status}"         # Variable dinámica
          inline: false
          enabled: true
        - name: "👥 Jugadores Online"
          value: "**{online_count}** conectados\n{player_list}"
          inline: false
          enabled: true

⚡ Métodos de Actualización

method: "update"
  • Edita el MISMO mensaje cada vez
  • Ideal para: Stats, leaderboards, bunkers
  • Ventaja: No llena el canal
  • Desventaja: No guarda historial
method: "create"
  • Crea un NUEVO mensaje cada vez
  • Ideal para: Alertas, warnings, fines, robos
  • Ventaja: Mantiene historial completo
  • Desventaja: Puede llenar el canal

🔧 Troubleshooting

❌ Webhooks no se envían

Verifica:
  • webhooks.enabled: true en config.yaml
  • El evento específico tiene enabled: true
  • El endpoint tiene enabled: true
  • La webhook_url es correcta y válida
  • El bot tiene acceso a internet

❌ Webhook se envía pero no se actualiza

Causas comunes:
  • method: "create" en lugar de "update"
  • El webhook fue eliminado de Discord
  • El mensaje original fue borrado manualmente
  • Cambió el ID del mensaje almacenado
✅ Solución:
Si usas method "update", NUNCA borres manualmente los mensajes de webhook en Discord. El bot necesita el mensaje original para editarlo.

❌ Variables no se reemplazan (aparecen como {variable})

Causas:
  • use_custom_templates: false en global config
  • Nombre de variable incorrecto
  • Variable no disponible para ese tipo de evento
